# Глоссарий

## Agent

Инженерная роль, выполняющая один этап процесса разработки.

Агент не является конкретной языковой моделью и может использовать любого совместимого AI-провайдера.

---

## Architecture Decision

Формализованное архитектурное решение, принятое для реализации задачи.

После успешного завершения задачи сохраняется в истории архитектурных решений.

---

## Architecture Memory

Общий архитектурный контекст проекта.

Используется всеми агентами перед выполнением задачи.

Содержит текущее состояние системы и ссылки на принятые архитектурные решения.

---

## Constitution

Набор инженерных правил проекта.

Определяет архитектурные ограничения и полномочия инженерных агентов.

Является обязательным для выполнения всеми участниками процесса.

---

## Current Task

Текущая инженерная задача, проходящая через конвейер обработки.

---

## Engineering Agent

Исполнитель инженерной роли в процессе разработки.

Каждый агент отвечает только за одну область ответственности.

---

## Orchestrator

Центральный компонент Forge.

Управляет последовательностью выполнения инженерных агентов, передает контекст и контролирует выполнение процесса.

Не принимает архитектурных решений.

---

## Pipeline

Последовательность этапов обработки инженерной задачи.

В базовой версии состоит из:

- Product Agent
- Architecture Agent
- Coding Agent
- Review Agent
- Testing Agent
- Release Agent

---

## Previous Decisions

Набор ранее принятых архитектурных решений, доступный всем инженерным агентам.

Используется для сохранения последовательности развития проекта.

---

## Project Metadata

Дополнительная информация о проекте, необходимая агентам для выполнения задачи.

Например:

- версия проекта;
- используемые технологии;
- структура модулей;
- конфигурация процесса.

---

## Prompt

Инструкция, определяющая поведение инженерного агента.

Описывает его роль, ограничения и ожидаемый результат работы.

---

## Provider Adapter

Компонент, обеспечивающий взаимодействие инженерного агента с конкретной языковой моделью.

Позволяет использовать различных AI-провайдеров без изменения внутренней логики Forge.

---

## Release Package

Итоговый результат прохождения задачи через конвейер.

Может содержать:

- изменения исходного кода;
- результаты проверки;
- тесты;
- описание изменений;
- служебную информацию.

---

## Review Report

Результат проверки реализации Review Agent.

Содержит список найденных нарушений, замечаний и итоговый статус проверки.

---

## Schema

Формальное описание структуры данных, используемой при обмене информацией между инженерными агентами.

Все взаимодействие в Forge осуществляется только через утвержденные схемы.

---

## Task

Структурированное описание инженерной задачи.

Включает:

- цель;
- ограничения;
- критерии приемки;
- дополнительный контекст.

Является основным объектом обработки в системе.
