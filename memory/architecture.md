# Architecture Memory

## Назначение

Architecture Memory — единый источник архитектурного контекста проекта.

Перед выполнением любой задачи каждый инженерный агент получает содержимое этого документа, чтобы принимать решения на основе текущего состояния системы, а не только входной задачи.

---

# Текущее состояние проекта

## Статус

MVP находится в разработке.

## Архитектурный стиль

Оркестрация инженерных агентов.

## Основной принцип

Каждый агент отвечает только за одну инженерную роль и взаимодействует с системой исключительно через Orchestrator.

# Архитектурные ограничения

- Агенты не взаимодействуют друг с другом напрямую.
- Все взаимодействие проходит через Orchestrator.
- Все агенты используют общий архитектурный контекст.
- Все инженерные правила определяются только Constitution.
- Каждый этап возвращает результат строго по утвержденному контракту.
- Нарушение Constitution приводит к остановке конвейера.
