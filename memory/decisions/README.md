# Architecture Decisions

## Назначение

Данная директория предназначена для хранения истории архитектурных решений проекта.

Каждое решение представляет собой отдельный документ и описывает изменение архитектуры, принятое в ходе развития системы.

История решений используется инженерными агентами как часть **Architecture Memory**, позволяя учитывать ранее принятые решения при выполнении новых задач.

---

## Формат хранения

Каждое архитектурное решение хранится в отдельном JSON-файле.

Рекомендуемый формат имени файла:

```text
YYYYMMDD_HHMMSS_<task-id>.json
```

Например:

```text
20260725_143000_TASK-001.json
20260726_091500_TASK-002.json
```

---

## Содержание решения

Каждый документ должен содержать:

- идентификатор решения;
- идентификатор исходной задачи;
- статус;
- краткое описание;
- затронутые компоненты;
- обоснование;
- риски;
- результат проверки Constitution.

---

## Правила

- Архитектурные решения сохраняются только после успешного завершения pipeline.
- Архитектурные решения не изменяются после утверждения.
- При необходимости создается новое решение, ссылающееся на предыдущее.
- Все решения должны иметь уникальный идентификатор.
- Решения являются частью долговременной памяти проекта.

---

## Статус

На текущем этапе разработки история архитектурных решений отсутствует и будет формироваться по мере развития проекта.
