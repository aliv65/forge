# Инженерные агенты Forge

## Назначение

Инженерный агент — это исполнитель одной инженерной роли в процессе разработки.

Агент не является самостоятельной системой принятия решений. Он работает в рамках своей ответственности, используя общий контекст проекта и соблюдая инженерные правила, определенные в Constitution.

Все агенты обладают одинаковым жизненным циклом:

1. Получение контекста.
2. Выполнение своей роли.
3. Проверка результата.
4. Передача результата следующему агенту.

---

# Общий контракт

Каждый агент получает:

- Current Task
- Constitution
- Architecture Memory
- Previous Decisions
- Project Metadata

Каждый агент возвращает строго определенный результат, который становится входными данными следующего этапа.

---

# Product Agent

## Назначение

Преобразует запрос пользователя в инженерную задачу.

## Ответственность

- анализ требований;
- выявление ограничений;
- определение критериев приемки;
- формирование структуры задачи.

## Получает

- пользовательский запрос;
- контекст проекта.

## Возвращает

Структуру Task.

## Не имеет права

- писать код;
- изменять архитектуру;
- выбирать технологии.

---

# Architecture Agent

## Назначение

Проектирует изменение системы.

## Ответственность

- анализ влияния изменений;
- выбор архитектурного решения;
- определение затрагиваемых компонентов;
- выявление рисков;
- проверка соответствия Constitution.

## Получает

Task.

## Возвращает

Architecture Decision.

## Не имеет права

- писать реализацию;
- изменять требования задачи.

---

# Coding Agent

## Назначение

Создает реализацию на основании архитектурного решения.

## Ответственность

- генерация исходного кода;
- соблюдение архитектурных ограничений;
- использование утвержденных интерфейсов.

## Получает

Architecture Decision.

## Возвращает

Implementation.

## Не имеет права

- изменять архитектуру;
- менять публичные контракты;
- принимать новые инженерные решения.

---

# Review Agent

## Назначение

Проверяет качество реализации.

## Ответственность

- поиск архитектурных нарушений;
- поиск дублирования;
- проверка соответствия Constitution;
- анализ читаемости;
- проверка полноты реализации.

## Получает

Implementation.

## Возвращает

Review Report.

## Не имеет права

- изменять код;
- изменять архитектуру.

---

# Testing Agent

## Назначение

Подготавливает тестовое покрытие.

## Ответственность

- генерация тестов;
- проверка критериев приемки;
- выявление потенциальных регрессий.

## Получает

Implementation.

## Возвращает

Test Suite.

## Не имеет права

- изменять реализацию;
- изменять требования.

---

# Release Agent

## Назначение

Подготавливает результат к публикации.

## Ответственность

- формирование итогового отчета;
- подготовка описания изменений;
- сбор информации о релизе;
- фиксация результатов выполнения задачи.

## Получает

Все результаты предыдущих этапов.

## Возвращает

Release Package.

## Не имеет права

- изменять код;
- изменять архитектуру;
- изменять результаты проверки.

---

# Взаимодействие агентов

```text
User Request
      │
      ▼
Product Agent
      │
      ▼
Architecture Agent
      │
      ▼
Coding Agent
      │
      ▼
Review Agent
      │
      ▼
Testing Agent
      │
      ▼
Release Agent
```

Каждый агент взаимодействует только с оркестратором.

Прямой обмен сообщениями между агентами отсутствует.

---

# Принципы работы агентов

Все инженерные агенты обязаны соблюдать следующие правила:

- выполнять только свою роль;
- использовать единый контекст проекта;
- соблюдать Constitution;
- работать только через формализованные контракты;
- не принимать решения вне своей зоны ответственности;
- возвращать воспроизводимый результат.

---

# Расширяемость

Архитектура Forge позволяет добавлять новые инженерные роли без изменения существующего процесса.

Возможные расширения:

- Security Agent
- Performance Agent
- Documentation Agent
- Database Agent
- UX Agent
- DevOps Agent

Добавление нового агента требует только:

1. описания роли;
2. определения входного и выходного контракта;
3. регистрации в оркестраторе.

Существующие агенты при этом остаются неизменными.
